# Results

This folder is scorer output. `results/*` is gitignored. `results/README.md` is the exception, so this note can be committed.

A result file is committed only on purpose:

- Task 4.3 commits one recorded live run, `results/live_<date>.json` and `results/live_<date>.md`.
- Task 5.1 commits the demo files on main: `results/demo_base.json`, `results/demo_head.json`, and `results/demo_comment.md`.

Every other run stays on the laptop. `results/head.json` and `results/head.md` from a local offline score are not committed.
